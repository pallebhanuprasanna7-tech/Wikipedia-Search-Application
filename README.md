# Wikipedia Search Application

A responsive Wikipedia search page built with HTML, CSS, Bootstrap, and JavaScript. Search for a keyword and view matching article titles, links, and descriptions.

## Run locally

Open `index.html` in a browser, or start a local web server from this folder:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## How to use

Enter a keyword in the search box and press **Enter**. Results are fetched from the CCBP Wikipedia Search API. An internet connection is required.

## Project files

- `index.html` — page structure and external library references
- `style.css` — page and search-result styling
- `script.js` — API request and dynamic result rendering
